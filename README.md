# Cavalli Estates

A luxury estate website for Cavalli Estates — a 137-acre private estate in Edna Valley, San Luis Obispo, California. Weddings & events, luxury residences, a working lavender farm, and an animal sanctuary.

Handcrafted static site (HTML / CSS / vanilla JS). Live preview via GitHub Pages.

Design: Cormorant Garamond + Jost · ivory / charcoal / bronze-gold.
